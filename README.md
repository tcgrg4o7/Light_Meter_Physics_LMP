# Light Meter Physics (LMP)

Light Meter Physics explores relativity, gravitational clock rates, and physical relationships expressed using light-travel time. The project emphasizes first-principles derivations, dimensional clarity, and worked examples connecting equations with physical interpretation.

Topics include relativistic energy and frequency, gravitational time dilation, thermal equilibrium in gravity, black-hole thermodynamics, and rotating black holes.

LMP uses time-based quantities to examine familiar relationships from another perspective. For example, Gτ = G/c³ is a rescaling of Newton’s gravitational constant, not a new independently measured constant. A change of units or notation alone does not establish new physics.

The manuscripts distinguish exact results from approximations and established physics from exploratory interpretations. Readers should consult each manuscript for its definitions, assumptions, references, and applicable limits.
